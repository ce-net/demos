ce-net / Demos

Ten demos.

Things a network of ordinary devices can do together. Each one is its own open-source repo, built from reusable cells, with its recorded proof inside.

Works re-run from a fresh clone, numbers reproduced
Partly code and recorded proof public; the note says what is missing

Works · 3

  • Works

    Render across devices

    One image, rendered by several machines at once. The result is pixel-identical to a single-machine render.

    A fresh clone renders the reference and the tiled frame, with one tile killed and retried, to the same hash.
    Source and proof
  • Works

    Kill a node, keep the data

    Kill the server holding the data, live. Every saved write survives, and the page proves it with a hash chain.

    Fresh clone: 3 leader kills, 351 acknowledged writes, every proof holds.
    Source and proof
  • Works

    An engineering result you can re-check

    A physics result that comes with a certificate. Re-check it in your own browser: same code, same inputs, same answer.

    Fresh clone: all 5 certificates verify; 440 of 440 tampered edits rejected.
    Source and proof

  • Partly

    One prompt, many devices

    Ask a question and see which device answers. When one device drops out, the answer keeps streaming from another.

    Recorded run: 98 tokens, 98 of 98 signatures valid, device switch at token 12. Live two-device page not public yet.
    Source and proof
  • Partly

    Follow-me cell

    A service that moves to whichever machine is closest to you, and keeps answering by the same name while it moves.

    The restart on one device is recorded. A move between two devices is not recorded yet.
    Source and proof
  • Partly

    Playground: deploy a cell in your browser

    Write a cell in your browser, deploy it to a real network, and call it from three languages, all within a minute.

    Code and tests for the sandbox, fuel limit and refusals are public. Hosted playground not live yet.
    Source and proof
  • Partly

    A stranger gets exactly one action

    We give you a key that does exactly one thing. Try to make it do more. Every attempt is refused, and the page shows you the rule that refused it.

    The build needs a protocol crate that is not published yet.
    Source and proof
  • Partly

    Same data, browser and terminal, live

    Change a value in your browser and see it change in a terminal and on a 3D factory map at the same moment. One schema, no server code.

    Recorded logs: 23 and 18 ms end to end, the same type error in Rust and TypeScript. Not yet re-run from a fresh clone.
    Source and proof
  • Partly

    Search everything you are allowed to see

    One search box across many machines. You only get back what your key allows, and the rest never leaves the machine it lives on.

    Recorded report: guest key 11 to 6 hits, engineer key 11 to 11. The build needs crates not published yet.
    Source and proof
  • Partly

    Any program becomes a mesh service in one command

    Turn any open-source program into a network service with one command. Then use it from your browser: same output, byte for byte.

    Tests pass and a local run reproduces the recorded output hash. Cross-machine parity not re-checked; one dependency not public yet.
    Source and proof
